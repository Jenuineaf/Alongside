Nothing about the design changed in the move. Why it had to move: the endpoint used to answer 204 No Content, which HTMX reads as "make no swap", so the bookmark was really saved but the icon stayed hollow until the next full page render. That reads as a broken button. Same contract as components/_spark.html: hx-post toggles, the view returns this partial, HTMX swaps it outerHTML, so the state comes from the server. Unlike Spark, a save is PRIVATE — it is never visible to anyone else and it shows no count, which is why this is brand-coloured rather than spark-*. Burnt orange belongs to Spark alone (design-system.md §4.4 rule 1). {% endcomment %}
