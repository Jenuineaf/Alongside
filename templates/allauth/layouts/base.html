WHY THIS FILE DECLARES ALMOST NOTHING base.html and allauth's templates both use a block called `content`. Django refuses two blocks of the same name in one template, so this layout deliberately does NOT redeclare it: allauth's children define `{% block content %}` and it flows straight through to base.html's `content`. The only real work here is mapping allauth's `head_title` onto base.html's `title`. Auth screens get a deliberately quiet header rather than components/_app_bar.html: the app bar links to posts:home, discovery:search and user.get_absolute_url, none of which exist yet, and a signed-out person on a login screen has nowhere to navigate to anyway. {% endcomment %} {% block title %}{% block head_title %}{% endblock head_title %}{% endblock title %} {% block nav %}
